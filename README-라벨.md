# SuperSplat — 세그먼트 라벨 (다중 라벨 판)

공식 SuperSplat v3.4.2에 **가우시안별 세그먼트 라벨 기능**을 추가한 버전입니다.
가우시안 하나가 **여러 개의 라벨을 동시에** 가질 수 있습니다.

---

## 실행

```bash
cd ~/Heritage_test/supersplat-labels
python3 serve.py
```

브라우저가 자동으로 `http://localhost:3000` 을 엽니다. 안 열리면 직접 주소를 입력하세요.
종료는 터미널에서 `Ctrl+C`.

포트를 바꾸려면 `python3 serve.py 8080`.

> **Chrome 또는 Edge에서 열어야 합니다.** WebGPU가 필요해서 Safari에서는 실행되지 않습니다.
> 설치할 것은 없습니다. 파이썬만 있으면 됩니다 (맥에 기본 포함).

---

## 다중 라벨이 동작하는 방식

라벨은 **레이어(layer)** 로 묶입니다.

- 한 가우시안은 **레이어마다 라벨을 하나씩** 가집니다.
- 레이어를 여러 개 만들면 그만큼 라벨이 병렬로 붙습니다.
- 레이어끼리는 아무 관계가 없습니다. 포함관계도, 순서도 없습니다.

```
가우시안 #4256
  부재    옥개석
  층      1층
  손상    균열A
```

같은 레이어 안에서는 라벨이 하나뿐이라 서로 모순될 수 없고,
레이어를 나누면 원하는 만큼 축을 늘릴 수 있습니다.

## 사용법

### 1. 라벨 붙이기

1. 오른쪽 툴바의 **🏷 버튼**으로 「세그먼트 라벨」 패널을 엽니다.
2. 맨 위에 **유물명**과 **유물 ID**를 입력합니다 (내보낼 때 파일명이 됩니다).
3. 선택 도구(사각형·브러시·올가미·구·상자·스포이드)로 가우시안을 고릅니다.
4. 패널의 입력칸에 **레이어 이름**과 **라벨 이름**을 넣고 「선택 영역 라벨 지정」을 누릅니다.
   - 레이어를 비워두면 `default` 로 들어갑니다.
   - 같은 레이어·같은 이름이 이미 있으면 거기에 추가됩니다.

### 2. 기존 라벨에 더 넣기

목록의 각 라벨 행에 버튼 3개가 있습니다.

| 버튼 | 하는 일 |
|---|---|
| ⊹ | 지금 선택된 가우시안을 이 라벨에 추가 |
| 🏷 | 이 라벨이 붙은 가우시안을 전부 선택 |
| 🗑 | 이 라벨 삭제 (붙어 있던 가우시안은 라벨만 풀림) |

레이어 헤더의 🗑 는 그 레이어를 통째로 지웁니다.

### 3. 라벨 확인하기

아래 툴바의 **🏷 라벨 도구**를 켜고 가우시안을 클릭하면,
그 가우시안이 가진 **모든 라벨이 레이어별로** 말풍선에 표시됩니다.
카메라를 돌려도 말풍선이 클릭한 지점을 따라갑니다.

### 4. 라벨 해제

선택한 가우시안의 라벨을 전부 푸는 것은 패널 아래 「라벨 해제」입니다.

## 파일 형식

「내보내기」를 누르면 `{유물ID}.labels.json` 이 저장됩니다.

```json
{
  "version": 3,
  "artifactName": "백제 금동대향로",
  "artifactId": "NT287",
  "numGaussians": 6611,
  "layers": ["부재", "손상"],
  "segments": [
    {"id": 0, "name": "뚜껑",  "layer": "부재", "color": "#e6194b"},
    {"id": 1, "name": "몸체",  "layer": "부재", "color": "#4363d8"},
    {"id": 2, "name": "균열A", "layer": "손상", "color": "#3cb44b"}
  ],
  "labels": [[0], [0, 2], [1], [], ...]
}
```

- `labels[i]` 는 **PLY 파일의 i번째 가우시안**이 가진 라벨 id 목록입니다.
- 라벨이 없으면 **빈 배열** `[]` 입니다.
- 한 레이어에서 라벨을 최대 하나 가지므로, 목록 길이는 레이어 수를 넘지 않습니다.

「가져오기」는 아래를 모두 읽습니다.

| version | 형식 | 처리 |
|---|---|---|
| 1 | `{"segments": [{"id","name"}], "labels": [3, -1, ...]}` | `default` 레이어로 들어감 |
| 2 | `{"segments": [{"id","partName"}], "labels": [3, -1, ...]}` | `default` 레이어로 들어감 |
| 3 | 위의 다중 라벨 형식 | 레이어 그대로 복원 |

## 주의사항

**PLY 파일 순서가 기준입니다.** SuperSplat은 파일을 불러올 때 가우시안을
공간 순서(Morton)로 재배열합니다. 가져오기·내보내기에서 이 순서를 되돌리므로,
JSON의 `labels` 배열은 **PLY 파일에 저장된 순서 그대로**입니다.
다른 도구에서 만든 JSON을 그대로 넣어도 맞고, 내보낸 JSON을 파이썬으로 읽어도 맞습니다.

**라벨은 원본 행 번호(sourceRow)에 저장됩니다.** 가우시안을 삭제해도
남은 가우시안의 라벨이 어긋나지 않습니다.

**PLY에는 저장되지 않습니다.** PLY와 JSON을 반드시 짝으로 보관하세요.
`.ssproj` 프로젝트 파일에도 들어가지 않습니다.

## 소스 수정하기

```bash
npm install          # 처음 한 번만
npm run develop      # http://localhost:3000, 저장하면 자동 반영
npm run build        # dist/ 다시 빌드
npm run lint:locales # 번역 키 정합성 검사
```

라벨 기능은 이 파일들에 들어 있습니다.

| 파일 | 역할 |
|---|---|
| `src/segments.ts` | 라벨 저장소. 레이어별 `Int32Array`(sourceRow → 라벨 id), 가져오기/내보내기 |
| `src/tools/label-tool.ts` | 클릭한 가우시안의 라벨 목록 말풍선 |
| `src/ui/segments-panel.ts` | 오른쪽 패널 |
| `src/ui/scss/segments-panel.scss` | 패널·말풍선 스타일 |
| `src/ui/svg/tag.svg` | 툴바 아이콘 |

기존 파일 중에는 `src/main.ts`(등록), `src/ui/editor.ts`(패널 배치),
`src/ui/right-toolbar.ts`·`src/ui/bottom-toolbar.ts`(버튼),
`src/ui/scss/style.scss`, `static/locales/*.json`(문구 23개)이 수정되었습니다.
